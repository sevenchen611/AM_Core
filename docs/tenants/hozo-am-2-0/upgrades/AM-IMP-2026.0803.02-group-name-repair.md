# AM-IMP-2026.0803.02 - HOZO AM 2.0 group name repair

Tenant: `hozo-am-2-0`  
Status: Ready

The legacy command `<绑定 HOZOAM 2.0 群组>` previously carried a historical display name. AM Platform now obtains the name from the current LINE group summary and, for an already-bound HOZO AM 2.0 group, repairs only the group identity metadata without resetting its operational configuration.

No tenant data, LINE ID, Notion ID, secret, or customer message is included in this record.
