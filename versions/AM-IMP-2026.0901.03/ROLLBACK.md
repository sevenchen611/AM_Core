# Rollback

1. Disable formal signing before rolling application code back; do not permit a preceding signer page to submit without both identity documents.
2. Preserve all private identity images, immutable signature snapshots, signing events, signed PDFs, and evidence receipts already created.
3. Never delete or overwrite identity evidence during rollback. Handle any retention or deletion request through an authorized personal-data procedure with an auditable legal decision.
4. Restore the package only after the signing page, private Drive checks, hash verification, and consent notice pass again.
