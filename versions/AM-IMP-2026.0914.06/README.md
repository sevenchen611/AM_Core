# 工程設計圖 Google Drive 版本庫

本套件在工程看板的「SOP-01／階段① 審圖與圖面定版」加入設計圖版本庫。

每次上傳都建立新的 Google Drive 檔案，不覆寫舊檔。Drive 目錄固定為：

```text
<租戶 Drive 根目錄>/設計圖/<專案名稱>/<圖面名稱>/<時間>_<版本>_<原始檔名>
```

租戶自己的 Notion「設計圖版本」資料庫只保存索引：專案、圖面名稱、版本、狀態、原始檔名、Drive 檔案 ID/連結、檔案類型、大小、版本說明、上傳人與時間。AMCore 不保存圖檔、專案資料、資料源 ID 或憑證。

## 使用方式

- 在階段①的設計圖版本庫按「上傳新版本」。
- 相同圖面沿用同一個圖面名稱，填入新的版本號與版本說明。
- 可標示草稿、送審、定版、發包版、變更版或作廢。
- 畫面依圖面分組，最新上傳版本置頂，同時保留所有舊版本的 Drive 連結。
- 單檔上限 500 MB，檔案由瀏覽器經 AM Platform 串流至 Google Drive，不寫入 AMCore 本機磁碟。

## 邊界與權限

所有 API 都先經既有 Portal 登入、工程模組租戶閘門與專案 scope 驗證。Drive 寫入只會發生在目前租戶宣告的根資料夾以下；Notion 索引只會寫入目前租戶宣告的 `DESIGN_DRAWINGS_DATA_SOURCE_ID`。
