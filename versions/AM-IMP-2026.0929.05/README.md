# Personal LINE review cards

Status: Ready. Adds optional bounded `cards` to the existing scoped messages API.
Personal transport clients can present a paginated task review workflow as a native
Flex carousel, with readable fields, postback/HTTPS buttons and gray unavailable
actions. Text and existing confirmation payloads remain compatible. The external
caller remains responsible for account authorization and business approval.

No schema, new key, customer data, or new permission scope is required.
