# 回退

1. 在實際部署環境將 `AMCORE_LINE_IO_ENABLED` 設成 `0` 或移除並重啟。新 API 變成 404，既有 LINE 路由與模組繼續執行；停用期間不保存此 API 的事件。
2. 每日審批程式停用輪詢與推播排程，保留最後成功 cursor、去重 key、未決發送清單。
3. 保留三張 `line_io_*` 表與去重資訊，不自動刪表。恢復啟用時先檢查未決發送，超過 retry window 不自動重送。
4. 如需回退程式，只撤銷本套件 `server.js` 整合段落與 `core/line-io/` 引用；不要覆蓋其他正在部署的改動，不改 LINE webhook URL。
5. 在專案自己的升級紀錄記錄回退與資料缺口。不得把未驗證部署留標為 Deployed。
