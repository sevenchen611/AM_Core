# Install

1. Install the updated contract signing service and web modules.
2. Run the signing service, signing web, runtime, and security-gate dry-runs.
3. Deploy the project-local Engineering AM runtime without changing the issued
   signing token, designated signer, LINE group binding, or contract state.
4. Open the existing LINE group signing link as a verified non-signer member.
5. Confirm the read-only inspection banner and full signer layout appear.

No database migration, environment variable, LINE invitation reissue, or
stored contract-data change is required.
