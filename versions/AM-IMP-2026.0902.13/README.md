# Read-only signer inspection mode

Verified members of a contract's bound LINE group can already read the frozen
PDF. This package also lets them inspect the same counterparty-data, identity
upload, consent, and signature layout shown to the designated signer, so an
internal coordinator can explain exactly where the signer must act.

Inspection is deliberately not signing authority. Every form control is
disabled, the signature canvas is inert, the submit control is locked, and the
server repeats the designated-signer identity check before accepting any
evidence. The inspection view does not mirror another person's live browser or
expose partially entered local form data.
