# Install

1. Deploy the updated contract workflow API, management service, and Engineering workspace.
2. No database DDL or environment-variable change is required.
3. Do not rewrite historical versions or physically delete Drive evidence.
4. Run the workflow API, management, workspace, draft-review, issuance, completion, and PDF-renderer dry-runs.
5. Verify protected attachments in an existing multi-version contract before using the exclusion control.
