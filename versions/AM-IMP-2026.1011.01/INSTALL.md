# Install

Apply the reviewed calendar extraction entrance and clock parser changes with the synthetic regression tests. No migration, new tenant enrollment, private-assistant activation or permission expansion is needed. Deploy reviewed GitHub main after CI to the actual target service.

For a specifically requested missed activity, first inspect the authenticated archive and tenant calendar requests read-only. Recovery may replay one verified original direct text event through the signed LINE entrance after the exact corrected commit is live. Preserve message/webhook identity, user/source and timestamp; omit expired reply credentials. The normal calendar worker creates a confirmation draft and sends a card. Never synthesize confirmation, change the date to replay time, bulk replay history or insert a Google event directly. Replayed events use the existing idempotency key and must not create duplicate drafts.

Only already configured targets are eligible. Keep production source records and secrets on the production host. Standalone HOZO_AM and SevenAM install and deploy separately when requested.
