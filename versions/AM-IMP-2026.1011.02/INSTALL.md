# Install

Apply the reviewed extraction, review/preview, confirmation-freeze and recovery-tool changes. No SQL migration, enrollment, permission expansion or general private-assistant activation is required. Deploy reviewed GitHub main after full CI to the actual target service.

For a specifically requested original blocked click, first inspect the tenant-local original draft/control read-only. Before refreshing its revision, run tools/retry-unprompted-calendar-previews.mjs with --tenant <enrolled-target> --retry-blocked-confirmation <original-private-draft-request-id>. Default is count-only. Apply only on the exact verified live commit with --apply --expected-commit <40-character-live-commit>. This requeues the original control; the normal worker rechecks the owner and creates the event. Do not bulk recover prior clicks, invent a confirmation, override a time blocker or expose private request identifiers in shared documentation.

Then use --tenant <enrolled-target> --refresh-cards for count-only inventory and the same guarded apply options for remaining active legacy cards. It does not confirm them. Existing saved, closed, expired or leased drafts remain excluded. Keep production source/evidence and secrets on the production host. Standalone installations remain separately requested work.
