# Engineering contract LINE file review

List archived files from the contract's bound LINE group beside internal review documents. Reviewers can open originals, classify quotation/drawing/other files, and explicitly retain selections in a new draft version. Nothing is automatically disclosed to contractors.

The existing attachment exclusion controls remove retained files from subsequent versions without deleting source records or Drive files. Missing archived originals require re-upload; temporary Notion URLs are not treated as durable evidence.

Formal contract links offer the exact issued version's original attachments to authenticated LINE group members. PDF and image attachments render in-page; DOCX, XLSX and DWG are downloadable originals. The attachment reader does not unlock signing consent.

Target: AM Platform Engineering tenant only. No schema migration, contract backfill, signing action, LINE notification, or HOZO/Seven data copy.
