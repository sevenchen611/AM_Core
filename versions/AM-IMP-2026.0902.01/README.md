# AM-IMP-2026.0902.01 - Historical LINE evidence and media-complete archives

Engineering contract managers can attach a private, hash-verified PDF for LINE history that predates the Engineering AM group binding. The supplemental archive is immutable, separately openable, and automatically included in current and future merged contract PDFs.

New LINE sticker messages retain their package/sticker identifiers so the archive renderer can embed the visual sticker. Photo evidence first uses the private Drive copy and falls back to the temporary Notion file when required.

Customer conversations and media are not stored in this package or repository.
