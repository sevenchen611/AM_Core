# Install

1. Apply the files listed in `upgrade.json` to AM Platform.
2. Run every command in `VERIFY.md`.
3. Deploy the Engineering AM service with the existing LINE and Notion
   configuration.
4. Re-send the onboarding command once in the intended LINE group:
   `綁定 工程 AM 群組：<群組名稱>`.
5. Confirm that the group receives either a binding confirmation or a visible
   failure reason.

No database migration or environment-variable change is required.
