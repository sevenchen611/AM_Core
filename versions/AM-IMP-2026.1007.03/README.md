# 每個 LINE 對話獨立 Notion 資料庫與 Drive 原檔

在簽章驗證後、私人助理暫停與業務分流前，將同一 OA 的群組、聊天室、私人訊息與其他事件存入部署專用 PostgreSQL 佇列。每個來源建立真正獨立的 Notion 資料庫，長文字分段保存；任意 LINE 二進位附件串流存到部署指定 Google Drive 母資料夾，Notion 只保留位置與驗證資料。

保留原租戶業務資料庫與歷史檔案。新附件由中央保存後，原租戶附件索引引用同一份已驗證原檔。機器人回覆、推播與請款獨立傳輸記錄發送結果，歸檔不會自行重送 LINE 訊息。

歷史補入優先使用可取得的原始 webhook，再讀各租戶 Notion 訊息／附件。缺少来源 ID 的記錄進入明確標示的待確認資料庫，不猜測私人使用者。未經系統接收的早期 LINE 歷史、已失效且沒有留底的附件，以及其他應用程式手動發送的訊息，不能憑空補回。

所有母頁 ID、Drive ID、OA ID、憑證與真實資料只存在部署設定／專案資料庫；升級包不包含任何生產資料。
