# AM-IMP-2026.0902.07 - LINE group contract read-only access

Formal Engineering AM signing links now separate document viewing from signing.
Every currently verified member of the contract's bound LINE group may inspect
the exact frozen PDF. Only the explicitly designated LINE user may enter the
counterparty details, upload identity documents, sign, or submit evidence.

Read-only group-member access does not advance the signing workflow and does
not create the designated signer's first-open evidence.
