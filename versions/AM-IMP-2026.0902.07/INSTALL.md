# Install

1. Apply the listed contract-signing service, web page, and dry-run files.
2. Run every command in `VERIFY.md`.
3. Deploy the Engineering AM service with its existing signing configuration.
4. Open an active invitation as a non-designated current group member and
   confirm read-only PDF access.
5. Open the same invitation as the designated signer and confirm that the full
   signing panel remains available.

No database migration or environment-variable change is required.
