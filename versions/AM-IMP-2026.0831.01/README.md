# AM-IMP-2026.0831.01 — Cross-version contract review history

Every completed draft-review response is retained as an immutable, version-labelled history item. A V2 review shows V1 feedback; V3 shows V1 and V2 feedback in chronological order.

The public review page displays prior feedback, Engineering AM continues to display the full internal review table, and the complete merged draft PDF appends a review-history section after the contract and source attachments.
