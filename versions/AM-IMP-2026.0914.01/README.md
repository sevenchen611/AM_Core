# AM-IMP-2026.0914.01 — 請款單群組發布與使用者選擇

Status: `Deployed` (AM Platform `1b6c7e5`; Render `dep-dajog6gae00c73echq80`; verified 2026-09-14)

在「請款單管理」為四張請款單分別設定適用 LINE 群組，按下正式發布後立即生效。
首次只選一個群組即可做 canary；未發布設定的群組維持既有 V3 入口，不受影響。

已發布設定的群組收到「請款」指令後，系統會先送出短效且限原申請人使用的 LIFF 選擇頁。
使用者選擇後，三張舊版表單會鎖定正確類型，V3 則由 Rental 重新驗證來源、成員與表單版本後核發入口。
