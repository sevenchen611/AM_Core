# AM-IMP-2026.0831.03 — Engineering contract internal review preview

Engineering AM now gives authorized staff a read-only document panel for every contract version. Staff can open a freshly generated, watermarked merged PDF and separately open each protected source attachment before approving or returning an internal-review version.

The preview is tenant- and project-scoped, verifies Drive privacy and SHA-256 integrity, includes historical draft-review feedback, and does not send LINE messages, change workflow state, store a signing artifact, or create signing evidence.
