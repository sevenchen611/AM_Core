# AM-IMP-2026.0902.09 - Mobile large signature pad

The Engineering AM formal-signing page now separates PDF review from the
actual electronic signature step. The PDF entry explicitly says that the PDF
is read-only and that drawing with a phone PDF viewer does not submit a
signature.

Designated signers receive a large, green-bordered signature canvas sized for
finger input on a phone. One submitted signature remains the authoritative
signature evidence and is inserted by the existing completion process into the
contract and promissory-note signature positions.
