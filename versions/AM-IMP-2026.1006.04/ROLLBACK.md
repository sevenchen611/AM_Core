# Rollback

Use the outside-repository application receipt with that project's LINE token. If it records a previous API default, set that ID again using `POST /v2/bot/user/all/richmenu/{richMenuId}`. If it records an Official Account Manager default or no API default, unset the new API default using `DELETE /v2/bot/user/all/richmenu` so the Manager setting can take effect again.

Verify the active menu. Keep original menus and do not remove user-specific menu links. No task or journal data changes are made by this package.
