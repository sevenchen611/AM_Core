# Engineering contract draft review

This package adds a non-binding draft-review path to the Engineering AM contract workspace. Staff may send an incomplete draft contract to the contract project's active LINE group before payment terms, acceptance criteria, or other final details are complete.

The generated PDF and public review page state that the material is a draft for discussion only. Opening it or responding does not create a signature, contract acceptance, or electronic-signature evidence. Reviewers can identify themselves and choose either `暫無修改意見` or `提出修改`, with comments recorded as evidence. Any revision is created as a new contract version; existing versions are never overwritten.

The formal signing workflow remains separate and retains all existing completeness, freeze, issuance, LINE identity, signer, and signature gates.

No contract records, LINE group IDs, reviewer data, tokens, production credentials, or Drive file IDs are stored in this package.
