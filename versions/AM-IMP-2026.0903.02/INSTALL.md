# Install

1. Install package `.01` first and verify the authority schema is ready.
2. Copy `contract-control-state.js`, `contract-control-center.js`, and
   `contract-control-center-web.js` with the `contracts.js` routes.
3. Keep the control endpoints read-only and protected by the existing
   project scope/contract-view capability.
4. Do not expose signing URLs, tokens, signer LINE IDs, IP addresses, or raw
   evidence hashes through the control center.
