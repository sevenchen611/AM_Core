# Engineering draft-review feedback presentation

This package presents a completed draft-review response in both required locations: the public draft page and the Engineering AM contract workspace. It preserves the reviewer, decision, complete response text, and response time.

Contract managers may start the next insert-only version from a change-request response. The new draft retains a `revisionSource` snapshot containing the source review id, source version number, reviewer, decision, complete response, and response time. The reviewed version is never overwritten.
