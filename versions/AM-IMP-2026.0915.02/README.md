# LINE group member claim auto-onboarding

An active claims group now treats an observed LINE member as an eligible applicant unless the finance administrator has explicitly disabled that member.

The AM authority registry persists only an opaque applicant reference beside its encrypted routing identity. Rental/Finance receives the raw LINE subject only transiently over the authenticated machine bridge, creates a claim-only external identity when necessary, and keeps employee and administrator capabilities separate.

This package does not publish forms to additional groups and does not change any existing claim or bank record.
