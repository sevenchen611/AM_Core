# Verify

- 同一位 LINE 使用者可在每種請款單保存最多 20 份具名範本，並於下次開啟時選擇套用。
- 可覆寫、重新命名及刪除自己的範本，且不會任意自動套用其中一份。
- 不同 LINE 使用者無法讀取或覆寫彼此範本。
- 同一使用者的四種表單及同表單內的不同具名範本互不覆寫。
- 舊版重新讀取即時群組綁定與送件權限後才可讀寫範本。
- V3 重新檢查 web session、來源、表單版本、付款方式、帳戶、廠商與表單定義。
- 資料庫範本 JSON 不含 LINE user ID、日期、服務月份、發票號碼、附件、OCR 或送件狀態。
- 執行 Rental Finance Claims 測試、AM claims authority dry-run、套件檢查與 alignment audit。
