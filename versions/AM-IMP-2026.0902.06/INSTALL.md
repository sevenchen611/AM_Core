# Install

1. Apply the listed runtime, workspace, and dry-run files.
2. Deploy the Engineering AM service.
3. Confirm the service recognizes schema
   `2026-09-02.engineering-contract-evidence.v5`.
4. Reload the approved or frozen contract and run the read-only signing
   readiness check.
5. Enable `ENG_CONTRACTS_SIGNING_ENABLED` only after an authorized operator
   explicitly approves activation. Activation and actual LINE issuance are
   separate actions.
