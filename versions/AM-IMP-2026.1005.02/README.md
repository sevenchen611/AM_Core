# AM-IMP-2026.1005.02 工程日誌工作內容與多位置

共用套件 Ready；AM Platform 工程租戶已於 2026-10-05 Deployed。此版接續 AM-IMP-2026.1005.01。

日誌取消獨立「今日進場工班」。使用者先選既有工項，工程名稱自動帶入且可修改，再填「工作內容」。每筆工作的最後一列填進場人數，並展開「現場空間 / 施工位置」以 checkbox 勾選多個同案件區域。工種由原工項帶入，不另填工班或工種。每份日誌同一工項仍合併成一筆，多個區域保存在該筆關聯中。

使用者已確認：每筆工作各自填人數，日誌顯示合計人次。同一批人參與兩個不同工項時可各自填入，合計是人次，不表示不重複的實際現場人數；任一工作人數未知則合計顯示待補，0 與未知分開。

新版回報使用 `format: work-content-v2`，工程名稱與逐筆人數保存於原始回報，施工索引與原工項／每個選取空間雙向連結。工程名稱不再寫入工班欄位。既有 Notion schema 與欄位保持相容，不需建庫或改環境綁定。旧版工班日誌仍可閱讀、重送及直接更新；原有來源、照片、預算／合約權限、施工日期排序與作廢證據規則持續生效。

可選同案件所有現場區域，預選原工項的空間；本次實際位置不修改原工項的計畫空間。租戶外、其他案件的空間仍拒絕。進度歷史於原工項與各選取空間下方顯示工程名稱、人數與全部空間名稱。
