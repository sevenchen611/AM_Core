# Install

1. Apply the listed Engineering AM runtime, completion, renderer, and dry-run files.
2. No PostgreSQL migration or environment-variable change is required; structured fields live inside each immutable version package.
3. Run every required dry-run in `upgrade.json`.
4. Render the synthetic signed QA PDF, convert every page to PNG, and inspect all pages.
5. Confirm the promissory note occupies exactly one page and the ID front/back share one protected appendix page.
6. Deploy the Engineering AM service and verify the authenticated next-version editor without saving a real contract version or sending LINE.
