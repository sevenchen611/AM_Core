# AM-IMP-2026.0902.02 - Contract next-version editor and single-source clauses

Engineering contract managers can create a later version without uploading unchanged contract documents again. The editor lists the currently effective contract body, construction drawings, and quotation, supports explicit replacement or exclusion, and keeps all earlier files as immutable version evidence.

Payment milestones and project-specific acceptance criteria are now structured, carried forward, and rendered inside Articles 5 and 10 of the contract body. Old schedule text is suppressed when structured payment data exists, while general invoice, inspection, defect-cure, and reinspection clauses remain intact.

Historical inherited files remain auditable through a version-evidence index but are not appended repeatedly to the current contract PDF. No customer files, contract values, or production credentials are stored in this package.
