# Install

1. Apply the listed runtime and dry-run files to the Engineering AM Platform service.
2. No PostgreSQL migration or environment-variable change is required.
3. Run the four required dry-runs from `upgrade.json`.
4. Render a representative multi-stage contract PDF and inspect every page.
5. Deploy the Engineering AM service and verify the authenticated contract workspace.
6. Confirm that starting V(n+1) lists V(n)'s effective body, drawings, quotation, payment milestones, and acceptance criteria.

Do not create a real contract version, replace a production attachment, or send a LINE draft during deployment verification.
