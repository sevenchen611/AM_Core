# AM-IMP-2026.0901.10 - Visible attachment removal and LINE archive recovery

Attachment exclusion controls are now permanently visible as larger red × buttons instead of remaining transparent until an exact pointer hover. This makes removal discoverable on desktop and touch devices while retaining the immutable next-version behavior.

The LINE archive area now reports the number of sent draft reviews and existing archives. When older reviews predate archive activation, a prominent green action explains and backfills those historical intervals without resending LINE messages. Future draft sends continue capturing their new conversation interval automatically.
